# Maintenance Playbook

## Normal operation
- Scheduled maintenance windows are planned and approved.

## Monitoring
- Node maintenance status, scheduler exclusion behavior, post-maintenance recovery.

## Failure symptoms
- Nodes unavailable after maintenance, lingering exclusion flags.

## Diagnosis
- Review maintenance state records, service status, connectivity checks.

## Recovery
- Re-enable nodes, clear stale maintenance flags, verify health before scheduling.

## Escalation
- Lab ops -> Platform ops -> Engineering lead.
