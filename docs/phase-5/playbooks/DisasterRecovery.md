# Disaster Recovery Playbook

## Normal operation
- Backups validated and recovery ownership assigned.

## Monitoring
- Backup freshness, restore test outcomes, recovery objective adherence.

## Failure symptoms
- Unrecoverable service state, major data loss, infra outage.

## Diagnosis
- Confirm outage class, data impact, and recoverability options.

## Recovery
- Restore DB snapshot, redeploy known-good artifacts, re-verify core workflows.

## Escalation
- Incident commander -> Infrastructure lead -> Release manager -> Executive stakeholders.
