# Incident Response Playbook

## Normal operation
- Incident channels and on-call roster are active.

## Monitoring
- Alert severity stream, paging acknowledgements, MTTA/MTTR tracking.

## Failure symptoms
- Sustained service degradation, data integrity risk, security alert.

## Diagnosis
- Triage scope, identify impacted subsystem, capture timeline and evidence.

## Recovery
- Apply approved mitigation/rollback, verify stability, communicate status updates.

## Escalation
- On-call engineer -> Incident commander -> Release manager -> Leadership.
