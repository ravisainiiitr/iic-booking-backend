# R6.4 — Discovery Engine

## Agent runtime (R6.1)

`CompositeSoftwareInventoryCollector` scanners:

1. Registry uninstall (HKLM 64/32 + HKCU) + exe guess
2. Start Menu shortcuts → `.exe`
3. Program Files + Program Files (x86) vendor-hint folders
4. Portable roots (`LocalAppData\Programs`, `PortableApps`, …)

Enrichment: FileVersionInfo publisher/version, optional SHA-256 (first 4MB) as `contentHash`.

## Incremental sync

1. Agent rescans (periodic or `REFRESH_SOFTWARE`)
2. Compares to local `inventory-snapshot.json`
3. Uploads `syncMode: "delta"` with `added` / `updated` / `removed` when churn is small
4. Falls back to `syncMode: "full"` on first sync, large churn, or admin refresh
5. Portal `InventoryService.synchronize` upserts; delta never soft-removes absent titles unless listed in `removed`

## Installer

Unchanged multi-scanner + catalog merge UI. Same inventory POST contract (now with optional `syncMode`).

## Catalog match / “Add as Custom”

- Installer: catalog merge + manual exe pick (existing)
- Runtime: unknown titles remain in inventory; operators add matching catalog entries via Catalog SPA (suggest Add as Custom = operator workflow, not auto-create)
