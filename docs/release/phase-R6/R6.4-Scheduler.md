# R6.4 — Scheduler

## Flow

1. Researcher opens Analysis Workspace for a booking (`GET /api/v1/bookings/{id}/analysis/`).  
2. Selects **workflow** and/or **equipment-mapped software** (R6 UI).  
3. `POST .../analysis/analyze/` with `workflow_id` / `software_slug` / `mapping_id` / `catalog_id`.  
4. `BookingRemoteAnalysisService.analyze_data` → `ensure_reservation(auto_allocate=True)`.  
5. `ReservationService` + `SchedulerService.allocate` → `AllocationService.select_best`.  
6. If no eligible PC → `ReservationQueue` (WAITING); drained by `process_queue`.  
7. Session launch via Guacamole; **workstation identity not returned** to the user.

## Hard filters (availability)

Path: `iic_booking/remote_analysis/services/availability.py`

- Online / enabled / not maintenance  
- Agent token present  
- `InstalledSoftware` matches required names (+ optional version)  
- License / `max_concurrent` when configured  

## Soft scoring

Path: `iic_booking/remote_analysis/services/allocation.py`

Health, CPU/memory load, software match weight, capabilities, department affinity, idle time, GPU, multi-software coverage, `EquipmentAnalysisPool.priority_boost`.

## R6 change

`ensure_reservation` in `equipment/remote_analysis_integration/service.py`:

- Prefer caller `required_software_names` (workflows).  
- Else require the **resolved** `SoftwareRequirement.software` only.  
- Else fall back to all equipment-mapped catalog names / legacy profile.
