# R6.3 — Inventory

## Surfaces

| Surface | Path |
|---------|------|
| SPA Installed Software tab | `/remote-analysis` → Installed Software |
| Fleet inventory API | `GET /api/v1/analysis/fleet/inventory/` |
| Software list API | `GET /api/v1/analysis/software/?q=&department=&licensed=` |
| Workstation detail | `GET /api/v1/analysis/workstations/{id}/` |

## Admin fields shown / returned

Status, department, session/reservation, booking id, installed software + versions, CPU/RAM/GPU, load (heartbeat), health, last seen / heartbeat age, license rows.

## Ops

- Periodic agent inventory (default interval from agent options)
- Admin command `REFRESH_SOFTWARE` forces a full multi-scanner rescan
- Sync never wipes metadata: upsert + soft `is_present=False`
