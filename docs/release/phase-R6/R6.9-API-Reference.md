# R6.9 — API Reference (single source of truth)

Mount: `/api/v1/analysis/`

## Catalog & mapping (R6.1 SPA)

| Method | Path | Notes |
|--------|------|-------|
| GET/POST | `catalog/software/` | SPA CRUD list/create |
| GET/PATCH/DELETE | `catalog/software/{id}/` | DELETE = archive |
| POST | `catalog/software/{id}/disable\|enable\|archive/` | |
| GET | `catalog/software/{id}/usage/` | |
| POST | `catalog/software/import/` | |
| GET/POST | `catalog/equipment-software/` | Mapping CRUD |
| GET/PUT | `catalog/equipment-software/matrix/` | Checkbox matrix |
| GET/PATCH/DELETE | `catalog/equipment-software/{id}/` | |

## Inventory / fleet (reuse)

| Method | Path |
|--------|------|
| POST | `inventory/` | Agent sync (`syncMode` full\|delta) |
| GET | `software/` | Installed software (+ search filters) |
| GET | `fleet/inventory/` | Enriched per-PC inventory |
| GET | `workstations/`, `workstations/{id}/` | |

| Method | Path |
|--------|------|

## Booking analysis (unchanged paths)

| Method | Path |
|--------|------|
| GET | `/api/v1/bookings/{id}/analysis/` |
| GET | `/api/v1/bookings/{id}/analysis/software/` |
| POST | `/api/v1/bookings/{id}/analysis/analyze/` |

## Deprecated / do not duplicate

- Do **not** add a second catalog table or `/software-catalog/` parallel API
- Lab `/api/inventory/*` is consumables — unrelated
- Legacy `bookings/.../analysis/*` twins remain for compatibility (same views)

## Permissions

- View: `CanViewRemoteAnalysis`
- Manage: `CanManageRemoteAnalysis`
- Agent: `IsRemoteAnalysisAgent` on inventory/heartbeat
