# R6.7 — Analysis Workspace

## Researcher UX

Route: `/analysis-workspace/{bookingId}`

Shows for each mapped software:

- Name, description, version constraint
- Typical usage
- Accepted file types
- AI tags (metadata display only)
- Launch CTA

## Never expose

RA hostname, IP, agent id, or PC picker. Portal auto-allocates.

## Launch body

`POST .../analysis/analyze/` with `mapping_id` / `catalog_id` / `software_slug` / `workflow_id`.
