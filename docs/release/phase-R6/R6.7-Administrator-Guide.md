# R6.7 — Administrator Guide

## Configure software catalog

1. Django Admin → **Analysis software catalog**.  
2. Set name, slug, vendor, version constraint, **license type**, max concurrent, departments, capabilities.  
3. Optional: AI readiness fields (`ai_tags`, `ai_metadata`) — metadata only.  
4. Saving ensures linked `SoftwareRequirement` via `ensure_software_requirement()`.

## Map equipment → software

1. Django Admin → **Equipment analysis software**.  
2. Pick equipment + catalog entry; mark one **default**; optional button label override.  
3. SPA Equipment form still has RA enable/session limits; free-text `analysis_profile` is legacy fallback (see note in `EquipmentForm.tsx`).

## Preferred Analysis PCs (optional)

Django Admin → **Equipment analysis pool** — priority boost only. Do not treat as exclusive ownership unless an `EQUIPMENT_PRIORITY` allocation rule is intentionally enabled.

## Monitor inventory

SPA → **Remote Analysis** (`/remote-analysis`):

- Workstations (online, health, agent version)  
- Installed Software (read-only agent inventory)  
- Heartbeats, Commands (including refresh software), Queue, Scheduler  

## Deploy / rescan agents

1. Run RA installer; confirm discovered software; link equipment department as required.  
2. Confirm inventory POST succeeded (portal shows software).  
3. Issue refresh-software command if apps change after install.
