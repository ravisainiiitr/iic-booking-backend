# R6.2 — Equipment Mapping

## Model

`EquipmentAnalysisSoftware` — Equipment → Catalog software. **Not** Equipment → RA PC.

Optional soft preference: `EquipmentAnalysisPool` (unchanged).

## SPA

| Route | Purpose |
|-------|---------|
| `/remote-analysis/equipment-software` | Dept → Equipment → Supported Software checkbox matrix |

- Filter by department / search equipment
- Check/uncheck catalog columns
- Set default software per equipment
- Save per equipment row (PUT matrix)

## APIs

| Method | Path |
|--------|------|
| GET/POST | `/api/v1/analysis/catalog/equipment-software/` |
| GET/PATCH/DELETE | `/api/v1/analysis/catalog/equipment-software/{id}/` |
| GET/PUT | `/api/v1/analysis/catalog/equipment-software/matrix/` |

Unique constraint `uniq_equipment_analysis_software` prevents duplicate mappings.

Booking Workspace still uses `GET /api/v1/bookings/{id}/analysis/software/` (read options only).
