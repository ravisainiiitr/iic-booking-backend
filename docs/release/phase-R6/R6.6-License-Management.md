# R6.6 — License Management

## Catalog `license_type` choices (R6.1)

| Value | Label |
|-------|-------|
| `unlimited` | Unlimited |
| `node_locked` | Node Locked |
| `concurrent` | Concurrent |
| `floating` | Floating |
| `network` | Network License Server |
| `dongle` | Dongle |
| `expired` | Expired |
| `other` | Other |

## Fields

- `max_concurrent` / `license_seats` — seat caps for concurrent/floating/network
- `license_server_url` — host/URL metadata for network/floating (hooks only)

## Scheduler respect

- `expired` catalog type → reject (`catalog_license_expired`)
- Unlimited → skip seat gate
- Concurrent/floating/network → seat check via `license_seats` or `max_concurrent`
- Node-locked / dongle → require `SoftwareLicense` row when `license_required`
- Network/floating → require server URL (catalog or per-WS) when `license_required`
