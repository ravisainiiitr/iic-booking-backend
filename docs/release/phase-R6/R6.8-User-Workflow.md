# R6.8 — User Workflow

## Happy path

1. Complete instrument booking as usual.  
2. Open **Analysis Workspace** (`/analysis-workspace/{bookingId}`).  
3. Choose input (booking RAW vs additional files) when prompted.  
4. If multiple workflows exist, pick a workflow.  
5. If equipment has catalog mappings, **select analysis software** (R6).  
6. Click **Open Analysis Environment** — portal allocates the best available PC that has the software.  
7. If busy, join the **queue**; position/ETA shown in Workspace / booking card.  
8. Work in the browser desktop; click **End Analysis** when finished.  
9. Download results from booking details (**Analyzed Data**).

## What users never do

- Pick a specific Analysis PC / hostname / IP  
- Manage licenses or catalog entries  

## Failure messages (examples)

| Situation | UX |
|-----------|-----|
| No software configured | Configure mappings / workflow (admin) |
| RAW not ready | Wait for sync |
| No PC with software | Queued or “no environment available” |

Infrastructure details stay hidden (see experience builder).
