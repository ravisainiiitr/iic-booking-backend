# R6.1 — Migration Report

## Migration

`remote_analysis.0023_r61_catalog_spa_fields`

Adds to `AnalysisSoftwareCatalog`:

- `typical_usage` (text)
- `accepted_file_types` (JSON list)
- `license_server_url`
- `license_seats`
- `is_archived`
- Extended `license_type` choices (unlimited, node_locked, concurrent, floating, network, dongle, expired, other)

## Deploy steps

1. Deploy backend with migration `0023`
2. `python manage.py migrate remote_analysis`
3. Deploy frontend (new SPA routes)
4. Roll agent build with composite collector (backward compatible inventory POST)

## Dual-read / no data loss

- Existing catalog rows keep prior `license_type` strings
- Equipment mappings unchanged
- Inventory upsert path unchanged for `syncMode=full` (default)
- Soft archive does not delete `EquipmentAnalysisSoftware` history until mappings are edited
