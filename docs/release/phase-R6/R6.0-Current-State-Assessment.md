# R6.0 — Current State Assessment

**Date:** 2026-08-07  
**Repos searched:** `iic-booking-backend-deploy`, `RemoteAnalysisAgent`, `iic-booking-frontend`, `DepartmentSyncAgent` (provisioning overlap only)  
**Method:** Code and migration path review — no assumptions of absence without file evidence.

## Executive verdict

Remote Analysis is **already largely software-centric**:

```
Department / Equipment → EquipmentAnalysisSoftware → AnalysisSoftwareCatalog
RA Agent → InstalledSoftware (+ hardware) via POST /api/v1/analysis/inventory/
Scheduler → InstalledSoftware match + scored AllocationService → best AnalysisWorkstation
User never selects RA PC (auto_allocate); optional EquipmentAnalysisPool is soft priority
```

Permanent exclusive **Equipment → RA PC** binding is **not** the default path. `EquipmentAnalysisPool` is an optional priority pool; hard filter only when an `AllocationRule` of type `EQUIPMENT_PRIORITY` is active.
