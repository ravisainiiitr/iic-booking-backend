# R6.3 — Software Discovery

## Current implementation (reuse)

### Installer (rich discovery)

| Component | Path |
|-----------|------|
| Orchestration | `RemoteAnalysisAgent/src/RemoteAnalysisAgent.Installer/Services/SoftwareDiscoveryService.cs` |
| Registry uninstall | `RegistryUninstallScanner` (HKLM 64/32 + HKCU) |
| Start Menu | `StartMenuShortcutScanner` |
| Program Files | `CommonFolderScanner` + scientific vendor hints |
| Catalog merge | `PortalInstallerClient.GetSoftwareCatalogAsync` → `GET /api/v1/analysis/installer/catalog/software/` |
| UI | `MainWindow.xaml` Software inventory panel |
| Sync | `PostInventoryAsync` / `InstallPipeline` after register |

### Agent runtime (periodic)

| Component | Path |
|-----------|------|
| Collector | `RegistrySoftwareInventoryCollector.cs` (uninstall registry) |
| Push | `AgentOrchestratorHostedService.PushInventoryAsync` |
| On demand | `RefreshSoftwareCommandHandler` (`REFRESH_SOFTWARE` / `REFRESH_INVENTORY`) |
| API | `POST /api/v1/analysis/inventory/` → `InventoryService.synchronize` |

### Portal ingest

```
payload.software | installedSoftware → InstalledSoftware upsert
payload.licenses | softwareLicenses → SoftwareLicense
hardware_* / hardware JSON → AnalysisWorkstation + WorkstationInventory
```

Path: `iic_booking/remote_analysis/services/inventory.py`

## Gaps / deferred

| Gap | Status |
|-----|--------|
| Agent Program Files / Start Menu parity with installer | Deferred — inventory already usable via installer + registry rescans |
| License fields on agent items often empty | Deferred |
| Installer GPU string empty | Deferred |
| Separate discovery microservice | **Not needed** — inventory sync is the discovery channel |

## Operator guidance

1. Prefer installer discovery + catalog checkboxes at deploy time.  
2. Use portal command **Refresh software** for rescan.  
3. Maintain catalog names so inventory display-name matching and scheduler `SoftwareRequirement.software` align.
