# R6.1 — Software Catalog Administration

## SPA

| Route | Roles |
|-------|-------|
| `/remote-analysis/software-catalog` | `remote_analysis.view` / `.manage`, admin, dept_admin |

### Capabilities

- Add / Edit catalog entries
- Disable / Enable / Archive (soft — never hard-delete)
- Import JSON array
- Search + filter (license type, active/archived)
- View usage (equipment mappings + installed matches)

## Backend (reuse `AnalysisSoftwareCatalog`)

| Method | Path |
|--------|------|
| GET/POST | `/api/v1/analysis/catalog/software/` |
| GET/PATCH/DELETE | `/api/v1/analysis/catalog/software/{id}/` |
| POST | `.../disable/`, `.../enable/`, `.../archive/` |
| GET | `.../usage/` |
| POST | `/api/v1/analysis/catalog/software/import/` |

Installer read API unchanged: `GET /api/v1/analysis/installer/catalog/software/`.

## Fields

Name, slug, vendor, version constraint, license type, max concurrent, license seats, license server URL, description, typical usage, accepted file types, category, AI tags/metadata, departments, active/archived.

Django Admin remains available as a fallback.
