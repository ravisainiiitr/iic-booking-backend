# R10.1 — Troubleshooting

## AWAITING_CHECKIN but UI shows queue / maintenance

**Symptoms:** "Scheduled Maintenance", "Waiting in queue", or unavailable banner while reservation is allocated.

**Check:**
- `GET /bookings/{id}/analysis/` → `experience.queue.is_queued` must be `false`
- `reservation.status` must be `AWAITING_CHECKIN`
- `reservation.allocated` must be `true`

**Fix (deployed R10.1):** Frontend reads `experience.checkin` and `awaiting_checkin`; backend `_queue_messaging` returns "Analysis Environment Allocated" when not queued.

## Check-in timer expired

**Symptoms:** Reservation returns to `QUEUED`, workstation released.

**Action:** Click Analyze Data again; scheduler re-allocates when a compatible PC is free.

**Do not:** Manually edit reservation/workstation rows in production DB.

## Stuck at "Synchronizing input data" (~40–49%)

**Cause:** Session `PREPARING` but RAA has no fresh heartbeat — `PREPARE_WORKSTATION` command stays `PENDING`.

**Check:**
- Workstation `last_heartbeat` age
- `RemoteCommand` for session `prepare_command_id`
- RAA service running on allocated PC

**Fix:** Ensure RAA service is running; session prepare requires live agent polling (not soft-online token alone).

## extension_grace_used NOT NULL violation

**Cause:** Schema drift — DB column exists, Django model omitted field.

**Fix:** Migration `0022_remotedesktopsession_extension_grace_used` + model field `default=False`.

## Guacamole fails after TOKEN_GENERATED

**Check:**
- `RemoteAnalysisSettings` Guacamole URL/credentials
- Reverse tunnel / ephemeral connection provisioning logs
- Session `failure_detail`

**Do not** iframe `/connect/` directly — SPA must exchange token via authenticated API.

## Queue row RESERVED while AWAITING_CHECKIN

**This is normal.** Queue row `RESERVED` means dequeued after successful allocation, not "user is waiting."

## No software mapping

**Expected user message:** "Remote Analysis is not configured for this equipment."

**Not:** generic Scheduled Maintenance or infinite queue.

## All compatible PCs busy

**Expected:** queue with position + "All compatible Analysis PCs are currently busy" (when implemented in maintenance hint path).
