# R10.2 — Session Troubleshooting

## Stale AWAITING_CHECKIN after timer

**Symptom:** Check-in `expires_at` is in the past but reservation status remains `AWAITING_CHECKIN`.

**Cause:** `CheckinService.expire_due()` is only invoked from Celery task `remote_analysis.expire_reservations`. If beat lags, holds stay reserved.

**Mitigations:**
1. Experience builder now calls `expire_due` when building UX for a past-due hold.
2. `launch_session` rejects expired check-in and runs `expire_due`.
3. Recover workflow: `Recover PXRD Booking RA Allocation` with hostname `RAVI`.

**Do not** manually edit reservation rows.

## Stuck RESERVED workstation with no heartbeat

**Symptom:** e.g. `DESKTOP-CSMH6BU` status `RESERVED`, `last_heartbeat=None`.

**Cause:** Offline detector previously required `last_heartbeat < cutoff`, so NULL heartbeats never flipped OFFLINE.

**Fix:** `mark_stale_workstations_offline` includes NULL heartbeats and protects `AWAITING_CHECKIN` holds.

## Data Workspace shows "Path will appear when Analysis PC is ready"

**Cause:** Production backend lacked R9 workstation path fields / experience `data_workspace`.

**Fix:** Migration `0023_r9_workstation_data_workspace`, heartbeat path ingest, experience payload.

Paths populate after the agent reports `dataRoot` / `inputPath` / `outputPath` in heartbeat (RAA ≥ R9 data workspace build).

## Session stuck PREPARING / Synchronizing input data

1. Confirm allocated host has **fresh heartbeat**.
2. Inspect `PREPARE_WORKSTATION` RemoteCommand status.
3. Soft-online (token only) is insufficient for prepare — agent must poll.

## Guacamole TOKEN_GENERATED but blank desktop

Do not mark ACTIVE. Check:
- Token exchange via authenticated `/session/{id}/connect/`
- Reverse tunnel / ephemeral connection
- Session `failure_detail` (no secrets)

```bash
gh workflow run "Recover PXRD Booking RA Allocation" \

  -f hostname="RAVI"
```
