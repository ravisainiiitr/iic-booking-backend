# R10.1 — Remote Analysis State Machine

## Reservation lifecycle

```
REQUESTED / VALIDATING
    ↓
QUEUED                    (ReservationQueue.status = WAITING)
    ↓ allocate
RESERVED                  (transitional, during allocation)
    ↓ open_checkin_window
AWAITING_CHECKIN          (ReservationQueue.status = RESERVED, dequeued)
    ↓ user Start / launch
RESERVED                  (check-in accepted)
    ↓ create_session
PREPARING
    ↓ agent PREPARE_WORKSTATION complete
READY
    ↓ Guacamole provision + token
TOKEN_GENERATED / LAUNCHED
    ↓ browser connect
CONNECTING → CONNECTED → ACTIVE
    ↓ end session
COMPLETED / CANCELLED / EXPIRED / FAILED
```

## Session lifecycle (parallel)

```
(none)
    ↓ launch_session
CREATED → PREPARING → READY → TOKEN_GENERATED → LAUNCHED
    → CONNECTING → CONNECTED → ACTIVE
    → TERMINATED / COMPLETED / EXPIRED / FAILED
```

## Queue row semantics

| ReservationQueue.status | Meaning |
|-------------------------|---------|
| `WAITING` | In FIFO scheduler queue |
| `ALLOCATING` | Scheduler attempting allocation |
| `RESERVED` | **Dequeued** — PC assigned; not waiting |
| `EXPIRED` / `CANCELLED` | Terminal |

**Important:** `AWAITING_CHECKIN` + queue row `RESERVED` is **correct** — the user holds an allocated PC and is not in the waiting queue.

## API flow (SPA)

1. `GET /bookings/{id}/analysis/` — summary + `experience.checkin`
2. User clicks **Start Analysis**
3. `POST /bookings/{id}/analysis/analyze/` → `awaiting_checkin: true` OR direct launch path
4. Navigate to `/analysis-launch/{id}`
5. `POST /bookings/{id}/analysis/launch/` — accepts check-in, creates session
6. `GET /analysis/session/{id}/connect/?t=` — Guacamole client URL
7. iframe desktop → `ACTIVE`

Alternative explicit endpoint: `POST /bookings/{id}/analysis/start/` (SPA uses launch path).

## Workstation status during hold

During `AWAITING_CHECKIN`, workstation is `RESERVED` (held for user, not available to scheduler).

## Check-in expiry

If timer expires before Start:

```
AWAITING_CHECKIN → QUEUED (re-enqueue) or CANCELLED (policy)
Workstation → AVAILABLE
```

Policy: equipment `analysis_missed_checkin_policy` (default: end of queue).
