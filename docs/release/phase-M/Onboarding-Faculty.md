# Faculty Onboarding

## Getting started

1. Open https://equip.iitr.ac.in and sign in with institute credentials.  
2. Ensure wallet / department sub-wallet has balance (or follow recharge process).  
3. Browse equipment → select instrument → choose slot → enter formula inputs → Book.  

## After booking

1. Mark **Sample Sent** with identifiers when samples leave your lab.  
2. Track status on booking detail / notifications.  
3. When results are ready, download from the booking (internal).  
4. For Remote Analysis–enabled completed bookings: **Analyze** → Start → browser desktop → End when finished.  
5. Download invoice PDF from the booking.  

## Tips

- Use valid instrument inputs (example PXRD: A=1, B=10, C=80, D=0.02, E=0.5).  
- Wallet is debited at booking per charge profile.  
- Contact Lab Incharge for sample receipt issues.
