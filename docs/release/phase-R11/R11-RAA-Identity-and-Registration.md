# R11 — RAA Identity and Registration

RAA is an independent Remote Analysis Workstation.

- Enrollment uses existing portal auth (Main Admin / Department Admin).
- Department/Equipment linking is **optional** (preferred pool only).
- Registration payload does not require equipment binding.
- Identity fields: agent_id, hostname, MAC, IP, OS, RAA version, heartbeat, data root, inventory.

See also: R11-Software-Catalog.md, R11-Allocation-Logic.md
