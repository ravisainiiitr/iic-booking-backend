# Wallet Credit Facility — Financial Reconciliation

## Ledgers (linked, not conflated)

1. **Wallet ledger** — `SubWallet` / `SubWalletTransaction` (source of wallet balance)
2. **Credit facility ledger** — `WalletCreditLedgerEntry` (WALLET_CREDIT / CREDIT_REPAYMENT / …)
3. **Invoice** — demand for settlement amounts
4. **Payment / receipt** — `WalletCreditPayment`

Outstanding (facility) = credited − repaid + adjustments − reversals.

Never edit `outstanding_amount` without a ledger entry (`recompute_outstanding`).

## Consistency checks

For each facility, `reconcile_facility` / `reconcile_wallet_credit` verifies:

- Cached `outstanding_amount` matches ledger-derived outstanding
- Sum of `CREDIT_REPAYMENT` entries equals sum of payment receipts
- Active invoice outstanding matches facility outstanding

## Machine-readable output

See `wallet_credit_reconciliation.json` (generated by management command; empty/zero when no facilities).

## Old automatic credit

Automatic ₹1000 / negative-balance floors are **disabled**. Historical wallet
transactions are **not** rewritten. Existing temporary-credit / faculty facility
rows remain for audit only and no longer grant overdraft.
